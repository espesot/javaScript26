### Practica N 2
### Alumno: Spesot Enzo



#### Uso de ciclos de iteracion

##### Planteo del problema
>Se crea un calculador de promedios de notas que fue teniendo el alumno durante el año
se utiliza una **const** para determinar la cantidad de examenes que se tomaron
Luego se pide que se ingrese el nombre del alumno o el numero **0 (cero)** para salir

>Una vez que el usuario ingreso el nombre del alumno a travez de un **for** se va pidiendo el resultado de los examenes. Cuando se termina de completar la carga el sistema calcula el promedio y de acuerdo al resultado indica que debe hacer el alumno

- 8 o mas Promocion directa
- 7 o 6 rinde solo la teoria
- 5 o 4 rinde la materia completa
- menos de 4 debe recursar

>Al finalizar imprime un mensaje con el resultado y solicita al usuario que ingrese un nuevo alumno o salga
