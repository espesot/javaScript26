#### Arrays

##### Planteo del problema
>Este simulador de **Lista de Alumnos** utiliza el array **alumnos = []** para guardar todos los alumnos registrados.
Se le pide al usuario que ingrese una opcion de acuerdo a lo que desee realizar.

>Luego de ingresar una opcion y si es correcta se utiliza un **switch** para seleccionar el camino adecuado en base a la opcion ingresada.
>Cada caso del switch tiene asiganada una funcion con la cual el sistema resuelve la peticion del usuario.

>Se utilizaron varios metodos de array para cumplir con los pedidos
> **unshift()** Para ingresar un nuevo registro al principio del array
> **push()** Para ingresar un registro al final del arrays 
> **includes()** Para determinar si un registro existe o no
> **indexOf()** Para determinar la posicion de un elemento determinado en el array
> **splice()** Para buscar un elemento y modificarlo dentro del array
