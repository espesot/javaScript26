##### Planteo del problema
>Se crea un calculador de promedios de notas que fue teniendo el alumno durante el año
se utiliza una **const** para determinar la cantidad de examenes que se tomaron

>Se utiliza la funcion **acumularNota()** donde se pasa por parametero la cantidad de examenes y devuelve la sumatoria de todas las notas del alumno

>Se usa una funcion **flecha** donde se le pasa por parametro el **return** de la funcion anterior y la cantidad de examenes para calcular el promedio final

- 8 o mas Promocion directa
- 7 o 6 rinde solo la teoria
- 5 o 4 rinde la materia completa
- menos de 4 debe recursar

>Por ultimo se utiliza una funcion **resultado()** donde se pasa por parametro el promedio y devuelve un mensaje para el alumno.

>Al finalizar imprime un mensaje con el resultado y solicita al usuario que ingrese un nuevo alumno o salga
