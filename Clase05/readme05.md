### Manejo de Objetos


>Para la resolucion de este practico se planeto lo siguente
- Creacion de una clase **Producto**
- Creacion de 3 instancias
- Creacion de 2 Metodos

### Metodos empleado

> **updateStock(cantidad)** con este metodo lo que haces es modificar el stock del producto se puede utilizar tanto para una venta pasando la cantidad en negativo o para aumentar la cantidad de stock que se tenga

> **descuento(porcentaje)** Este metodo nos devuelve el precio final al aplicarle un porcentaje de decuento que se desea realizar
